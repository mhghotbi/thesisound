Use URL Context to capture the selected source for an auditable evidence pipeline.

Rules:
- Do not use the search snippet as source text.
- Preserve the source's meaning, paragraph order, headings, qualifications, and explicit uncertainty.
- Exclude navigation, cookie notices, advertisements, related-links widgets, and comments unless comments are the declared source.
- Do not summarize, expand, translate, or combine the source with outside knowledge.
- Mark access as full_text only when the complete declared article/page/document scope was available.
- If only an abstract, preview, fragment, metadata, or inaccessible page was available, report the honest access level and limitations.
- canonical_url must identify the retrieved source.
